# Vault Validation Checklist

Use this checklist after applying the skill to confirm that the Obsidian vault is usable by both a human and an AI agent.

## 1. Structure

- [ ] The vault has a clear inbox/capture area.
- [ ] Raw sources and processed notes are separated.
- [ ] Top-level folders are understandable without explanation.
- [ ] There are not too many folders for a new user.
- [ ] The user knows where tomorrow's first note should go.

## 2. Capture flow

- [ ] There is a path for quick ideas.
- [ ] There is a path for full web/video/PDF/source captures.
- [ ] The user can turn a raw source into a processed note.
- [ ] Important source material is preserved before summarization.

## 3. Templates

- [ ] Source note template exists.
- [ ] Processed note template exists.
- [ ] Project or area note template exists if needed.
- [ ] Templates include enough metadata to be searchable.

## 4. Agent readability

- [ ] The vault path is stable and accessible to Hermes or another agent.
- [ ] There is a schema/index/rules note explaining the vault layout.
- [ ] The agent knows which folders are safe to edit.
- [ ] The agent knows which folders contain preserved sources.
- [ ] The agent is instructed to patch notes carefully instead of rewriting everything.

## 5. Sync and backups

- [ ] The sync method is chosen deliberately.
- [ ] The user understands conflict risks.
- [ ] Backups are configured or planned.
- [ ] Mobile usage was considered if relevant.

## 6. Plugin discipline

- [ ] Only required plugins are enabled at first.
- [ ] Optional plugins are documented separately.
- [ ] Dataview/tasks/calendar plugins are added only if the user wants that complexity.

## Done means

The vault is ready when the user can capture one real source, process it into a useful note, find it later, and let an AI agent read the structure without guessing.

# Roadmap

This roadmap keeps the project focused on useful, verifiable improvements.

## Near term

- Add tested examples for different user profiles: creator, founder, student, researcher, and team knowledge base.
- Improve the installation instructions with screenshots or short video references.
- Add a simple validation checklist for a finished Obsidian vault.
- Add more templates for source notes, processed notes, project notes, and index notes.

## Later

- Add multilingual documentation.
- Add examples for larger vault migrations.
- Add safer agent-operation rules for editing, linking, and preserving notes.
- Collect feedback from real users and turn repeated problems into skill improvements.

## Principles

- Keep the default setup small.
- Preserve raw sources.
- Make the system easy for humans and agents to read.
- Avoid plugin overload.

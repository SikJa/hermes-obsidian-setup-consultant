# Example: Founder / Creator Vault

This example shows how the skill can be applied for a founder, creator, consultant, or solo operator who wants Obsidian to become a business memory and AI-readable knowledge base.

## Use case

The user wants to save:

- business ideas;
- content ideas;
- client notes;
- research sources;
- scripts and prompts;
- decisions and operating rules;
- useful references for AI agents.

## Recommended structure

```text
00 Center/
  Inbox/
  Templates/
  Indexes/
01 Business/
  Offers/
  Clients/
  Sales/
  Operations/
02 Content/
  Ideas/
  Scripts/
  Published/
03 Projects/
04 AI System/
  Agent Rules/
  Prompts/
  Workflows/
05 Learning/
06 Personal/
90 Sources/
  Web/
  Videos/
  PDFs/
  Transcripts/
```

## Capture workflow

1. Save everything quickly into `00 Center/Inbox/`.
2. Preserve full source material inside `90 Sources/`.
3. Create a processed note in the relevant business/content/project folder.
4. Link the processed note back to the original source.
5. Add decisions, next actions, and open questions.

## Minimal plugins

- Obsidian Web Clipper
- Templates
- Canvas
- Graph view

Optional later:

- Excalidraw for diagrams
- Dataview for dashboards
- Tasks if the user wants task management inside Obsidian

## Agent rule example

```text
Before editing this vault, read 00 Center/Indexes/Vault Schema.md.
Preserve raw sources in 90 Sources/.
Create processed notes separately.
Patch existing notes carefully.
Do not reorganize top-level folders without explicit approval.
```

## Success criteria

The setup works if the user can capture a video, preserve the transcript, generate a processed note, link it to a project, and ask an AI agent to find it later.
